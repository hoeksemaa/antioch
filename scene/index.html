Find the person at the front door, frame by frame

A simulated doorbell camera at five houses. Python captures each frame from the Three.js scene and scores off-the-shelf person detectors against the true position of the person.

// How it works

One scene, one harness, any detector

Three.js · scene/

Scene

Five houses with different entries, one person, one package. The scene is a pure function of time and seed, so every frame replays exactly.

Python · bench/capture.py

Capture

Playwright opens the scene in headless Chromium, sets the time, and takes the doorbell frame and the true box around the person.

Python · bench/detector.py, run.py

Score

Pretrained COCO detectors look for people in each frame. A hit overlaps the true box with IoU ≥ 0.3. Results go to this page.
